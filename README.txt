README
Setup del Percorso:
1. Linea Guida: Il tracciato principale deve essere costruito utilizzando un nastro di colore blu, che definisce la traiettoria che il sistema dovrà seguire. 
2. Curve del Percorso: Definire le curve con il nastro, per definire l'andamento del percorso
3. Segnaletica Orizzontale: In prossimità della curva è obbligatorio posizionale l'apposita segnaletica orizzontale, definendo il lato in cui deve continuare la navigazione.

Setup Dispositivo:
Tenere il dispositivo ad una altezza pari a circa 130cm, altezza del busto, parallela al pavimento. 

Avvio del progetto:
Avvio del framework ngrok in locale sul computer, e in seguito avvio dello script python Main.py. Attraverso il dispositivo personale, accedere al server locale esposto da ngrok attraverso il browser in modo da accedere alla PWA. 
È possibile, ma non necessario, scaricare l'applicazione in locale. In seguito, seguire le indicazioni presenti all'avvio della PWA, permettendo l'accesso alla fotocamera e al microfono. Seguire le indicazioni fornite dal dispositivo.
In caso si voglia attivare il riconoscimento dell'ambiente circostante, interagire con il pulsante "Parla con l'assistente", dopo aver esposto la richiesta premere il pulsante "Ferma e invia", per permettere di validare la richiesta. Attendere feedback dal dispositivo. Per chiudere la funzionalità operare nel medesimo modo esprimendo la propria richiesta. 
Per chiudere il sistema cliccare sul tasto "Spegni sistema".
